FOLDER GAMBAR HERO & BANNER WILD & GREEN
==========================================

Folder ini digunakan untuk meletakkan gambar tampilan atas (Hero Banner) dan dekorasi aplikasi:

1. banner.png / character.png
   - Gambar karakter anak / ilustrasi utama di sebelah kanan banner atas.
   - Format: PNG (dengan latar belakang transparan atau menyatu dengan warna kuning ceria).
   - Ukuran rekomendasi: lebar ~400px - 800px.

2. logo.png
   - Logo judul "Wild & Green" di pojok kiri atas banner.
   - Format: PNG transparan.

3. bottom-leaves.png
   - Hiasan dedaunan alam di bagian bawah di belakang navigasi menu.

TIPS:
Cukup ganti file di folder ini (misalnya timpa character.png atau banner.png) dengan gambar Anda, maka tampilan di aplikasi akan otomatis langsung berubah sesuai gambar baru Anda!
