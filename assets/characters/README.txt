============================================================
📁 FOLDER KARAKTER WILD & GREEN
============================================================

Kamu bisa menyimpan gambar karakter custom kamu di folder ini!
Contoh format yang didukung:
- PNG (.png) (direkomendasikan dengan background transparan)
- JPG / JPEG (.jpg / .jpeg)
- SVG (.svg)
- WebP (.webp)

Karakter bawaan yang sudah disiapkan:
1. lion.svg     -> Karakter Singa Penjelajah
2. fox.svg      -> Karakter Rubah Cerdik
3. panda.svg    -> Karakter Panda Peneliti
4. bird.svg     -> Karakter Burung Rimba
5. frog.svg     -> Karakter Katak Petualang
6. koala.svg    -> Karakter Koala Ramah

Untuk menambahkan atau mengganti karakter:
Cukup paste gambar kamu ke folder ini, lalu daftarkan nama file
dan nama karakternya di file `src/data/characters.js`.
============================================================
